
# 🔐 Gerador de Senhas em Python

Primeiro projeto desenvolvido em Python como parte da minha jornada de aprendizado em programação.

## 📌 Sobre o projeto

Um gerador de senhas aleatórias que permite ao usuário escolher o tamanho da senha, com validação de entrada e geração segura de caracteres.

## ✨ Funcionalidades

- Geração de senhas aleatórias.
- Letras maiúsculas e minúsculas.
- Números e caracteres especiais.
- Tamanho personalizável de 1 a 128 caracteres.
- Validação de entradas inválidas.
- Tratamento de erros.

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca secrets
- Biblioteca string

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute no terminal:

```bash
python main.py
```

4. Informe o tamanho desejado para a senha.

## 📚 Conceitos praticados

- Variáveis
- Strings
- Condicionais (`if`)
- Laços de repetição (`while` e `for`)
- Tratamento de exceções (`try/except`)
- Importação de módulos
- Geração de valores aleatórios seguros
